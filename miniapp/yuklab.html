⬇️ Ilovani yuklab olish (APK)

Hajmi ≈ 30 MB · Wi-Fi orqali yuklash tavsiya etiladi

O'rnatish — 3 qadam

  1. «Ilovani yuklab olish» tugmasini bosing va yuklanish tugashini kuting (pastki qatordagi foiz 100% bo'lsin). Если браузер спросит «Всё равно скачать?» — нажмите Скачать.
  2. Yuklangan PrepWay.apk faylini oching: Chrome'dagi «Открыть» tugmasi orqali yoki Файлы → Загрузки (Download) papkasidan.
  3. Telefon ruxsat so'rasa: «Настройки» → «Разрешить из этого источника» ni yoqing → orqaga qayting → «Установить».

«Не удалось открыть файл» chiqsa

  1. Faylni Telegram yoki boshqa ilova ichida ochmang. Shu sahifani Chrome brauzerida oching va qaytadan yuklab oling.
  2. Faylni «Файлы» / «Мои файлы» / «Проводник» ilovasi orqali oching: Загрузки (Download) → PrepWay.apk.
  3. Fayl to'liq yuklanganini tekshiring: hajmi ≈ 30 MB bo'lishi kerak. Kichikroq bo'lsa — o'chirib, qaytadan yuklang.
  4. Fayl nomi .apk bilan tugashi kerak (masalan PrepWay.apk). .bin yoki .zip bo'lsa — qayta yuklang.

Ruxsat berish (telefon rusumi bo'yicha)

Xiaomi / Redmi / POCO

Настройки → Приложения → Разрешения → Установка из неизвестных источников → Chrome (yoki «Проводник») ni yoqing.

MIUI «Проверить приложение» desa — «Установить» ni bosing.

Samsung

Настройки → Приложения → ⋮ → Особые права доступа → Установка неизвестных приложений → Chrome / «Мои файлы» → Разрешить.

Boshqa Android (Honor, Realme, Tecno, Infinix, Vivo…)

Настройки qidiruviga «неизвестн» deb yozing → «Установка неизвестных приложений» → Chrome / Файлы → Разрешить.

«Заблокировано Play Защитой» chiqsa

«Подробнее» → «Всё равно установить» ni bosing. Prep Way hali Google Play'da emas, shuning uchun Google uni tanimaydi — bu oddiy holat.

«Приложение не установлено» chiqsa

Telefonda Prep Way'ning eski versiyasi boshqa imzo bilan o'rnatilgan bo'lishi mumkin. Eski Prep Way ilovasini o'chiring va qaytadan o'rnating. Xotira yetarliligini ham tekshiring (kamida 150 MB bo'sh joy).

iPhone versiyasi tez orada. Savollar bo'lsa — ilovadagi «Yordam» bo'limiga yozing.
